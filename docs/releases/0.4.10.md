## Fixes

- Fix extra backticks corrupting an opening fenced code block when Obsidian restores a note at startup (#124).
- Fix rule-editor rendering and mouse/arrow-key cursor positioning in a separate Settings window (#125).
- Make selected Profile labels readable in the light theme.
- Keep active conversion rules intact while validating valid or invalid Settings drafts.
- Use the current editor's file metadata for code-block protection, so background indexing of other notes cannot disable normal formatting or expose code to automatic spacing.
- Cancel delayed conversions when typing, cursor movement, note/Profile changes or editor removal makes their original positions stale. This prevents late clipboard results from overwriting newer text or moving the cursor. Canceled conversions leave the typed trigger unchanged.
- Fix WASM initialization compatibility with the updated toolchain and runtime.

## Improvements

- Name Profile commands after the actual Profiles and dynamically register/unregister them (#123).
- Update the development toolchain and document installation, builds, local deployment and Hot Reload.
- Add GitHub regression CI with 136 Vitest tests, compiled Rust/WASM integration, and 16 real Obsidian scenarios covering editing, undo/redo, Settings, clipboard behavior, background metadata and plugin reload.

## Compatibility

The minimum Obsidian version remains 0.15.0. File metadata lookup retains a fallback for older editor APIs. Automated UI checks run on Obsidian 1.14.4 (installer 1.9.14) on Linux; native IME composition, other desktop/mobile runtimes and interactions with other plugins are not covered by that suite.
